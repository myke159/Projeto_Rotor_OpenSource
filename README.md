# Projeto_Rotor_OpenSource
Controle de azimute com o desenvolvimento de um encoder rotativo Absoluto, utilizando um disco em código gray (8 bits), sensores, receptores, motor DC, IHM e microcontrolador. #OpenSource.

Este trabalho apresenta o desenvolvimento de um sistema microcontrolado para o posicionamento angular absoluto de um rotor de antena, visando atender às demandas de precisão e confiabilidade no radioamadorismo. A problemática central reside na perda de referência de posicionamento em motores convencionais após interrupções de energia, o que foi solucionado através da implementação de um encoder absoluto customizado de 8 bits. O protótipo utiliza um disco com codificação em Código Gray, processado por um Arduino Mega Pro Mini, garantindo a integridade dos dados durante as transições de estado e eliminando a necessidade de procedimentos de homing. O sistema conta com um circuito de potência baseado em modulação por largura de pulso (PWM) com o CI 555 para o controle de velocidade e ponte H para reversão do motor. A interface homem-máquina (IHM) é composta por um display LCD 20x4 com fontes customizadas, teclado matricial e sinalização sonora, permitindo a operação manual e o uso de presets geográficos para regiões como EUA, Europa e África através de um algoritmo de trajetória otimizada. Medidas de segurança foram integradas via software e hardware, incluindo um fim de curso instalado no limite de 180° para proteção dos cabos de alimentação. Os resultados demonstraram um sistema de baixo custo com resolução angular de aproximadamente 1,4°, provendo uma solução robusta e intuitiva para o direcionamento de antenas de telecomunicação.
